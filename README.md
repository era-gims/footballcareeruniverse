# Football Career Universe — Public Phone App

This folder is a Progressive Web App (PWA) package. It can be published for free with GitHub Pages, then installed from Chrome on Android as an app.

## Publish free with GitHub Pages

1. Create a new **public** GitHub repository.
2. Upload **all files and folders in this package** to the repository root.
3. In GitHub open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.
7. Open the Pages URL in Android Chrome.
8. Use Chrome's **Install app** / **Add to Home screen** option.

## What users get

- Blue and white football UI designed for phone screens.
- Player and Manager careers with separate saves.
- Live fixtures/results and league statistics.
- Match result celebration pop-ups.
- Career Shop using earned money for permanent player special skills.
- Retirement option from age 35 through 45.
- PWA installation and offline cache after the first hosted visit.

## Important

The game currently saves career progress in the device/browser's local storage. A public web address does **not** automatically synchronize a player's save across different phones.
