# Football Career Universe v9 — Audio Sources

The game includes an in-app online soundtrack selector using music published on OpenGameArt under **CC0**. The game streams the source files when online and falls back to its procedural WebAudio match soundtrack when external media cannot be loaded.

   https://opengameart.org/sites/default/files/The%20Rush_2.mp3

4. **Empacotatron Loop** — Fupi — high-energy techno / drums / arcade
   https://opengameart.org/content/empacotatron
   Direct file used by the game:

All four source pages identify the music as CC0. Check the source page and its current license notice before redistributing a future build.

## Important browser note

External soundtrack streaming requires network access. For installed/offline mode, FCU retains its procedural WebAudio fallback and match SFX. Android Chrome may also require one user tap before audio playback is allowed.
